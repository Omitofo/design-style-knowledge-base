# 01_color — Color Theory, Systems & Application

Color is one of the highest-leverage design decisions. This folder covers foundational theory from the most authoritative sources, practical systems, psychology, accessibility, and application rules.

## Core Authority Sources
- Josef Albers — *Interaction of Color* (perception and relativity of color)
- Johannes Itten — Bauhaus color theory (contrasts)
- Modern accessibility standards (WCAG contrast)
- Brand and UI system practice (Material, Apple HIG, etc.)

## Planned Structure
- `albers-interaction.md` — Key lessons from Interaction of Color
- `color-contrasts-itten.md` — Seven contrasts of color
- `palettes-and-harmony.md` — Practical palette construction
- `psychology-and-meaning.md` — Cultural and emotional associations (with caveats)
- `accessibility-contrast.md` — WCAG and practical contrast rules
- `digital-color-systems.md` — Working in RGB, HSL, design tokens, dark mode

Start with perception (Albers) before cultural meaning. Color is relative.
