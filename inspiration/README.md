# Inspiration — Brand & System Breakdowns

This folder contains structured analyses of highly successful visual systems from major brands. The goal is not to copy, but to extract transferable lessons about consistency, hierarchy, color, type, motion, and emotional positioning.

Each brand entry should cover:
- Overall design language / positioning
- Color system
- Typography system
- Layout & spatial principles
- Imagery / photography / illustration rules
- Motion / interaction (if relevant)
- Key dos and don’ts observable in the system
- What makes it distinctive and durable

## Planned / Priority Brands
- Apple (product + software design language evolution)
- Nike (energy, movement, athlete-centric)
- Amazon (utility, density, conversion-focused)
- Braun / Dieter Rams products (functional purity)
- Muji (Japanese minimalism / *muji* philosophy)
- Google Material Design (systematized digital language)
- Airbnb (friendly, photographic, human)
- Stripe / modern fintech (trust + technical clarity)
- Others as needed (Porsche, Rolex, Uniqlo, etc.)

Start with the brands that most closely match the emotional and functional goals of the current project.
