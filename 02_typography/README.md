# 02_typography — Type Principles & Practice

Typography is the primary vehicle of written communication in most design work. This folder draws from the most respected sources in the field.

## Core Authority Sources
- Ellen Lupton — *Thinking with Type*
- Robert Bringhurst — *The Elements of Typographic Style*
- Josef Müller-Brockmann / Emil Ruder / Armin Hofmann — Swiss tradition
- Practical system work (Apple San Francisco, Google Roboto/Material, etc.)

## Structure
- `lupton-thinking-with-type.md` — Key practical principles
- `classification-and-pairing.md` — Type classification and pairing logic
- `hierarchy-and-scale.md` — Building type scales and hierarchy
- `legibility-readability.md` — Spacing, measure, leading, contrast
- `web-and-ui-type.md` — Screen-specific considerations

Typography decisions should always be tested with real content at intended sizes.
