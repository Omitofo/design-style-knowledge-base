# Ellen Lupton — Thinking with Type (Core Ideas)

*Thinking with Type* is one of the most widely used practical introductions to typography for designers. It balances historical understanding with actionable rules and encourages both discipline and creative breaking of rules.

## Key Principles Summarized

### Letter
- Typefaces have personalities and historical baggage; choose with intention.
- Anatomy (x-height, ascenders, descenders, counters) affects legibility and texture.
- Avoid distorting type (stretching, fake bold/italic) — use designed variants.

### Text
- **Measure** (line length): roughly 45–75 characters for comfortable reading in body text.
- **Leading** (line spacing): generally 120–145% of type size for body text; tighter for display.
- **Alignment**: flush-left/ragged-right is often more readable than justified for continuous text, especially on screen.
- **Tracking and kerning**: optical spacing matters; avoid extreme tracking on body text.

### Grid
- Type lives on a grid (baseline grid, column grid). Aligning to a system creates coherence.
- Hierarchy is created through size, weight, color, position, and space — not decoration alone.

### Hierarchy
- Readers scan before they read. Create clear entry points and levels of importance.
- Limit the number of type sizes and weights in a system for coherence.

## Dos
- Choose typefaces that support the content’s voice and the medium’s constraints.
- Establish a limited, consistent type scale.
- Prioritize legibility for continuous reading; reserve expressive type for display moments.
- Test with real content, real sizes, and real users when possible.

## Don’ts
- Use too many typefaces or weights without a system.
- Ignore optical adjustments (type often needs slight tracking or size tweaks at extremes).
- Sacrifice readability for pure aesthetics in functional contexts.
- Treat type as pure decoration disconnected from meaning.

## Related
- Bringhurst for deeper, more literary treatment.
- Swiss sources for rigorous grid-and-type integration.
- Rams/Norman for the larger principle that type should serve understanding.
