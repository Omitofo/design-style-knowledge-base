# 03_layout-composition — Grids, Hierarchy, Space & Gestalt

Layout is the spatial organization of content. This folder covers the systems and perceptual principles that make compositions coherent and effective.

## Core Sources
- Josef Müller-Brockmann — *Grid Systems in Graphic Design*
- Gestalt psychologists (via design application)
- Classic composition principles (balance, contrast, alignment, proximity, repetition)
- Modern design-system practice (spacing scales, modular grids)

## Structure
- `grid-systems.md` — Practical grid construction
- `gestalt-principles.md` — Perceptual grouping laws
- `hierarchy-and-focus.md` — Creating clear visual paths
- `white-space.md` — Negative space as active element
- `modular-and-responsive.md` — Systems that scale across formats
