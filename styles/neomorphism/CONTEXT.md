# Neomorphism (Soft UI)

## Definition
Neomorphism (also called soft UI) is a short-lived interface trend (peak ~2019–2021) that uses subtle extruded or inset shapes, soft shadows, and low-contrast tones to create a soft, almost clay-like or embossed appearance. Elements appear to rise from or sink into a monochromatic or near-monochromatic background.

## Core Characteristics
- Soft, diffused shadows (both light and dark) creating emboss/deboss effects
- Low contrast overall; backgrounds and elements often share similar hues
- Rounded forms and smooth surfaces
- Minimal color; reliance on lighting cues for hierarchy
- Tactile, almost physical softness without full skeuomorphism

## Dos
- Maintain extremely consistent light direction
- Use the effect sparingly on key interactive elements
- Pair with stronger contrast for text and critical actions if needed
- Test thoroughly for accessibility (low contrast is the main risk)

## Don’ts
- Apply neomorphism to large areas of text or complex layouts
- Rely on shadow alone for interactive affordance without additional cues
- Use it in high-information-density interfaces
- Ignore the accessibility problems inherent in low-contrast soft UI

## Particularities
- Visually distinctive for a brief period; now largely considered a dated trend.
- The core idea (soft depth through dual shadows) can still be used selectively, but full neomorphic interfaces are rarely recommended for production systems.
- Accessibility is the primary practical limitation.

## How to Achieve
1. Choose a mid-tone background.
2. Create elements with both a light shadow and a dark shadow opposite each other.
3. Keep color saturation low.
4. Limit the effect to a few key components.
5. Always provide alternative high-contrast states for accessibility.

## When to Use
- Experimental, portfolio, or short-lived marketing pieces
- Situations where a soft, tactile, almost physical quality is specifically desired
- As a limited accent rather than a full system

## When to Avoid
- Production applications, design systems, or any context requiring strong accessibility and longevity
- Data-heavy or productivity tools

## Related
- Sits between Flat Design and Skeuomorphism
- Shares soft-depth interests with Glassmorphism but uses different techniques
- Largely superseded by more accessible and flexible systems
