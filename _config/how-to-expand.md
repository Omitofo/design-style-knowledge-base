# How to Expand This Knowledge Base

This repository is intentionally incomplete. It is a living ICM-style knowledge tree. Follow these conventions when adding content.

## File Structure Conventions
- Each major style lives in `styles/<style-name>/CONTEXT.md` (and optional supporting files).
- Brand inspirations live in `inspiration/<brand>/CONTEXT.md`.
- Principles and foundational theory live in numbered top-level folders (`00_`, `01_`, etc.).
- Keep files focused. Prefer multiple linked files over one giant document.

## Content Quality Bar
- Ground claims in named, high-authority sources whenever possible.
- Distinguish historical fact, principle, and practical recommendation.
- Always include Dos / Don’ts / When to use / When to avoid.
- Note connections to other styles and to the core principles in `00_principles/`.

## Suggested Next Additions
- More styles: Postmodern, Punk/Grunge, Glassmorphism, Material Design, Vaporwave, Luxury Minimal, Constructivism
- More brands: Braun, Muji, Stripe, Airbnb, Google Material, Porsche, Uniqlo
- Deeper color, type, and layout files
- Motion and interaction principles
- Accessibility deep-dive
- Cultural / regional design notes (Japanese *ma*, Scandinavian functionalism, etc.)

## For LLM Use
When directing an agent, point it at the smallest set of files that answer the current question. The folder hierarchy is the scoping mechanism.
