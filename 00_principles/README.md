# 00_principles — Macro Design Principles

These are the foundational "macro nodes". They are the stable Layer 3 reference material that should inform almost every design decision.

## Core Sources (highest authority)

| Principle Set | Originator | Key Work |
|---------------|------------|----------|
| Ten Principles for Good Design | Dieter Rams | Less But Better / Braun work |
| Human-Centered Design / Affordances | Don Norman | The Design of Everyday Things |
| Grid Systems & Clarity | Josef Müller-Brockmann | Grid Systems in Graphic Design |
| Data Integrity & Clarity | Edward Tufte | The Visual Display of Quantitative Information |
| Typography as Thinking | Ellen Lupton | Thinking with Type |
| Gestalt Principles | Wertheimer, Koffka, Köhler (via design application) | Classic psychology applied to layout |
| Direct Manipulation & Visibility | Ben Shneiderman | Various HCI works |

## Files in this folder
- `rams-ten-principles.md` — Canonical 10 principles with explanations and modern application
- `norman-affordances-signifiers.md` — Core concepts from The Design of Everyday Things
- `swiss-clarity-objectivity.md` — Foundational Swiss/International values
- `tufte-data-principles.md` — Clarity, integrity, and "above all else show the data"
- `gestalt-principles.md` — Proximity, similarity, continuity, closure, figure-ground, etc.
- `lupton-type-thinking.md` — Key ideas from Thinking with Type

Start here before diving into any individual style.
