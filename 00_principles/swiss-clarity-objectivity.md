# Swiss / International Style — Core Values of Clarity & Objectivity

The Swiss Style (International Typographic Style) is both a historical movement and a set of enduring values. Beyond the visual traits (grid, sans-serif, asymmetry), its deepest contribution is a philosophy of design as clear, objective communication.

## Core Values

### Clarity
Every element should serve the communication of the message. Ambiguity is minimized. Hierarchy is explicit. The reader should not have to fight the design to understand the content.

### Objectivity
The designer’s personal expression is subordinated to the needs of the message and the audience. Photography is preferred over illustration when neutrality is desired. Type and layout are tools, not stages for self-display.

### Universality
The style aspired to transcend national and linguistic boundaries. Clean sans-serif type, logical structure, and reduced cultural ornament were meant to make information accessible across contexts.

### Systems Thinking
Grids, modular type scales, and consistent rules allow work to be extended by others and applied across many formats. The system is more important than any single artifact.

## Practical Implications
- Prefer structure over decoration.
- Make hierarchy legible at a glance.
- Document the rules so the system can live beyond one designer.
- Use reduction as a tool for focus, not as an aesthetic end in itself.

## Tension with Other Styles
These values are in productive tension with Postmodern play, Maximalist energy, Punk rawness, and purely expressive approaches. The Swiss contribution is not that it is the only valid way to design, but that it provides a high standard of clarity against which other approaches can be measured.
